Equivalence

BOLT and UPX assume transforms do not break logic. Edge-case crashes and alignment bugs exist. A local sandbox must run the project test suite before a certificate is issued.

Pareto conflict

UPX shrinks disk and can raise cold start plus RSS via the unpack stub. The product must sit on a size↔speed frontier, not blindly compress.

Manifest gap

A 30% RSS win is worthless on the bill if Helm still requests 512Mi. Artifact and runtime gains have to rewrite resources.requests.

Who pays

Platform / DevOps

Registry cost and 1–3 GB images that miss HPA SLAs. Slimming has been shown to speed deploys ~5×.

Indie / vibe coders

OOM-kills on small VPS. No LLVM expertise. They need a drag-and-drop local tool.

HFT / games

Microsecond p99 and L1 i-cache layout. BOLT-class 10–15% CPU is the pitch.

ESG / FinOps

Scope 3 software carbon. GSF SCI certificates are the enterprise wedge.
